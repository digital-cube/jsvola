Most deployments run the Docker image and use one of the client packages. Reach for `@vol-a/server` only to embed vola in your own Fastify application.

<PackageTable />

## Which one do you need

| You are | Install |
| --- | --- |
| Calling a vola server from a backend or a browser | `@vol-a/client` |
| Drawing files in a React app | `@vol-a/react`, `@vol-a/client` and their peers |
| Mounting vola inside Fastify | `@vol-a/server`, `@vol-a/core` |
| Sharing types with your own HTTP client | `@vol-a/core` |

The `vola` command line (`@vol-a/cli`) is already inside the image, and `@vol-a/lookups` is what the server uses for its controlled vocabulary.

## The image

`ghcr.io/digital-cube/jsvola` holds the server, the worker, the command line, the examples site and the tools the worker needs. The tags and every setting are in the [deployment guide](https://github.com/digital-cube/jsvola/blob/main/docs/DEPLOYMENT.md#the-image).
